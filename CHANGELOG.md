# Changelog

## 1.0.0 — Site de vendas Nutrição Sem Culpa
- Landing page evergreen completa com as 17 seções especificadas.
- Config central de preços e links de checkout (`lib/config.ts`).
- `CheckoutButton` como único ponto de saída para pagamento, com fallback
  profissional quando o link ainda não está configurado.
- Camada de rastreamento com 11 eventos preparados, sem IDs fictícios.
- Schema.org Product, Person e FAQPage; sitemap e robots.
- Páginas institucionais: privacidade, termos, política de compra.
- Capas e páginas de exemplo extraídas dos PDFs reais para os mockups.
